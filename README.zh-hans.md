## 介绍

蒙太奇字幕组素材库为社群成员、贡献者和合作伙伴提供标准化的官方组织和媒体资源。

本仓库包含蒙太奇字幕组的Logo、社交媒体资源等视觉设计资源，支持多种格式和分辨率，适应不同的应用场景。

## 目录结构

### [Logos](./logos/)
组织官方Logo资源，包含多种格式（PNG、SVG）和分辨率。适用于网站、应用、社交媒体和印刷用途。

### [Banners](./banners/)
社交媒体标题横幅和相关视觉资源，为不同社交平台优化。

## 许可证

本仓库中的所有资源均根据各自目录中的许可证发布。请在使用前查看相应目录的LICENSE文件。
