## 介绍

蒙太奇字幕社区素材库为社区成员、贡献者和合作伙伴提供标准化的官方组织和媒体资源。

本仓库包含蒙太奇字幕社区的 Logo、社交媒体资源等视觉设计资源，支持多种格式和分辨率，适应不同的应用场景。

## 目录结构

### [Logos](./logos/)
组织官方 Logo 资源，提供**扁平版**（纯色墨黑与黄色）和**照片版**（原始霓虹摄影）两种视觉风格，每种风格均包含多种格式（PNG、ICO、SVG）和分辨率。适用于网站、应用、社交媒体和印刷用途。

### [Banners](./banners/)
社区社交媒体头图的原始摄影作品与署名信息。

## 许可证

本仓库中的所有资源均根据各自目录中的许可证发布。请在使用前查看相应目录的 LICENSE 文件。
