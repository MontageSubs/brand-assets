## About

The MontageSubs Brand Assets repository provides standardized and consistent brand resources for community members, contributors, and external partners. This centralized collection ensures visual consistency and accessibility across all MontageSubs initiatives and collaborations.

This repository contains logos, social media assets, and visual design resources for MontageSubs, available in multiple formats and resolutions to support diverse use cases and applications.

## Repository Structure

### [Logos](./logos/)
Official brand logos in multiple formats (PNG, SVG) and resolutions. Suitable for websites, applications, social media, and print materials. Includes comprehensive design guidelines and usage recommendations.

### [Banners](./banners/)
Social media banners and visual assets optimized for various platforms. Pre-scaled and formatted to meet platform specifications while maintaining brand consistency.
